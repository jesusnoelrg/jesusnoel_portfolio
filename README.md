# Portafolio Profesional — Jesús Noel R. G.

Bienvenido al repositorio de mi portafolio web personal. Este sitio fue diseñado y desarrollado con un enfoque en **rendimiento, arquitectura limpia y componentes accesibles**, sirviendo como carta de presentación para mis proyectos de ingeniería de software y desarrollo web.

🌐 **Sitio Web en Vivo:** [jesusnoel-portfolio.vercel.app](https://jesusnoel-portfolio.vercel.app/)

---

## Tecnologías utilizadas

- **Framework:** [Astro](https://astro.build/) (Renderizado estático súper rápido y arquitectura de islas)
- **Frontend / UI:** React, TailwindCSS
- **Lenguaje:** TypeScript / JavaScript
- **Despliegue:** Vercel

---

## Sobre Mí

Soy **Ingeniero de Software** enfocado en la arquitectura de sistemas, la optimización de bases de datos y el desarrollo backend robusto. Me apasiona erradicar el código espagueti y diseñar soluciones escalables estructuradas bajo el patrón MVC, APIs REST y buenas prácticas de diseño.

No creo en las soluciones "mágicas", sino en la ingeniería bien estructurada.
